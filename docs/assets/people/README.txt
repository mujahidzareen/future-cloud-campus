FCC illustrative tutor portraits

Website assets:
- tutor-illustrations.webp: original fictional portraits 1–6.
- tutor-illustrations-2.webp: original fictional portraits 7–12.

Both are 1536x1024 3-by-2 illustration sheets. CSS selects square cells without modifying facial content. The generated PNG originals remain in the generated_images workspace directory. The project copies are WebP encodings for efficient web delivery. No real staff photographs or likeness claims are made.

Created using built-in image generation; no API/CLI fallback was used. These images and fictional first names belong only to the clearly labelled example profiles. Approved staff profiles remain a separate configuration path.

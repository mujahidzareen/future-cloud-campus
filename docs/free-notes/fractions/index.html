Equivalent fractions and addition

Equivalent fractions represent the same proportion. For addition, express the fractions using a common denominator.

Primary Maths · Primary / middle

Core ideas

  1. Multiply or divide the numerator and denominator by the same non-zero number to make an equivalent fraction.
  2. Choose a common denominator before adding fractions with different denominators.
  3. Add the numerators, keep the common denominator and simplify when possible.
WORKED EXAMPLE

To add 1/3 and 1/4, use denominator 12. Then 1/3 = 4/12 and 1/4 = 3/12. The sum is 7/12.

Try it yourself

Attempt each question before opening the answer.

1. Write 1/2 with denominator 8.

4/8

2. Find 1/5 + 2/5.

3/5

3. Find 1/2 + 1/4.

3/4

Balancing chemical equations

A balanced equation has the same number of atoms of each element on both sides. Change coefficients in front of formulae.

Chemistry · GCSE / IGCSE

Core ideas

  1. Write the correct chemical formulae first.
  2. Count each element on the reactant and product sides.
  3. Adjust coefficients and recount. Use the smallest whole-number ratio. Do not change subscripts to balance an equation.
WORKED EXAMPLE

For hydrogen reacting with oxygen, start H₂ + O₂ → H₂O. Balance oxygen with 2H₂O, then hydrogen with 2H₂. The result is 2H₂ + O₂ → 2H₂O.

Try it yourself

Attempt each question before opening the answer.

1. Balance Mg + O₂ → MgO.

2Mg + O₂ → 2MgO

2. Balance N₂ + H₂ → NH₃.

N₂ + 3H₂ → 2NH₃

3. Why must the subscript in H₂O stay unchanged?

Changing a subscript changes the substance's formula.
